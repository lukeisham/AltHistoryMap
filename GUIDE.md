# AltHistoryMap — Guide

## Purpose

A zoomable Mercator world map for building alternative histories, with a flag designer and a crest maker. Input: people create imaginary maps, flags and crests. Output: saved imaginary maps, flags and crests. A map is one file holding its paint, markers, flags, crests and countries; flags and crests also save as PNG. Essential functions: painting territory on a 4096 x 4096 grid in three layers (Political, Province, Culture); cities, flags, symbols and labels as markers; flags as palette grids that take a stamped coat of arms; pop-ups defining heraldic and flag terms; each Political colour as a country that takes a crest and flag and holds key facts, with generators steered by its philosophy.

It is a static site, public on GitHub Pages, and runs on Luke's Macs through `serve.py`. It reads no other Lukeatron app, store or file, and `app/` must stay deployable on its own.

## Cross-boundary behaviour

The base map is rasterised at build time so the browser loads one small file and never parses geometry; scenarios use the map-file format so the app opens one with the one reader it already has. Styling is split across many CSS files that all read the one `tokens.css` (the HouseStyle token layer, the map-ground tokens and four 0-to-1 numbers the looks read); no other file writes a literal colour, size or duration, and the renderer reads its colours from the same tokens.

Tests run with `node --test tests/*.test.js` and `python3 -m unittest discover -s tests -p "test_*.py"`.
