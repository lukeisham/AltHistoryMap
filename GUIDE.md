# AltHistoryMap — Guide

## Purpose

A zoomable Mercator world map for building alternative histories, with a flag designer and a crest maker. Input: people create imaginary maps, flags and crests. Output: saved imaginary maps, flags and crests. A map is one file holding its paint, markers, flags, crests and countries; flags and crests also save as PNG. Essential functions: ready-made scenario maps to start from; painting territory on a 4096 x 4096 grid in three layers (Political, Province, Culture); cities, colonies, flags, symbols and labels as markers that appear by zoom level; country names drawn over their land; flags as palette grids that take a stamped coat of arms and show enlarged under the pointer; an eye-dropper beside each colour swatch; crash recovery of unsaved work; pop-ups defining heraldic and flag terms; each Political colour as a country that takes a crest and flag, holds key facts, can answer to another country as a dominion, client state or colony chosen by right-click, and has generators steered by its philosophy. Performance: a frame costs 16 milliseconds or less, so pan, zoom and painting stay smooth on a laptop.

It is a static site that anyone can play online at `https://althistorymap.pages.dev/app/` (Cloudflare Pages) or `https://lukeisham.github.io/AltHistoryMap/` (GitHub Pages), or download from the public GitHub repository `lukeisham/AltHistoryMap` and run locally with `serve.py`, as it does on Luke's Macs. It reads no other Lukeatron app, store or file, and `app/` must stay deployable on its own.

Run without a terminal it opens no browser and keeps exactly 8801. `--port N` and `--no-browser` are its only options | A write route would need the request gate; an inline script or a remote file in `app/` is blocked by the policy |
| `Start AltHistoryMap.command` | `serve.py` | Runs `serve.py` from the app folder | The launcher opens nothing |
| `System/Apps/ports.json` | `serve.py`, the launcher | Port 8801 | The launcher and the Home tile open a dead address |
| `System/Tools/appservers/appservers.py` | `serve.py` | Starts it, restarts it when a `.py` is newer | The local copy goes down or serves stale code |
| `System/Apps/Home/catalog.json` | `serve.py` | Launch kind `server`, entry `serve.py`, port 8801 | The Home tile fails to open the app |
| the public repo `lukeisham/AltHistoryMap` | GitHub Pages at `https://lukeisham.github.io/AltHistoryMap/`, and Cloudflare Pages at `https://althistorymap.pages.dev/app/` | A root `index.html` and `.nojekyll`; the site is served from a sub-path, so every URL in `app/` is relative (`data/basemap.bin`, `data/scenarios/`) and none begins with `/` | A root-absolute URL loads nothing on the live site; anything in `app/` that needs Lukeatron paths or a Python server fails there |
| `.github/workflows/publish-althistorymap.yml` | the public repo `lukeisham/AltHistoryMap` | On each push to `main` that changes `System/Apps/AltHistoryMap/`, it runs both test suites, then mirrors the folder into the public repo with the Actions secret `PUBLIC_REPO_TOKEN` (a fine-grained token with Contents write on that repo only). It leaves `issues.md` (private) out and keeps `index.html` and `.nojekyll` (public only). GitHub Pages and Cloudflare Pages (`https://althistorymap.pages.dev/app/`) rebuild from that commit | A missing or expired secret fails the run and the public copy goes stale; a failing test blocks publishing |

The base map is rasterised at build time so the browser loads one small file and never parses geometry; scenarios use the map-file format so the app opens one with the one reader it already has. Styling is split across many CSS files that all read the one `tokens.css` (the System Style token layer, the map-ground tokens and four 0-to-1 numbers the looks read); no other file writes a literal colour, size or duration, and the renderer reads its colours from the same tokens.

Tests run with `node --test tests/*.test.js` and `python3 -m unittest discover -s tests -p "test_*.py"`.
